# 05. 跨会话记忆评测

> 本专项用于验证 Pico 分层记忆系统能否在多轮和跨会话场景下准确召回关键证据、覆盖过期知识（`supersede`）、物理隔离恶意注入（`quarantined`），并降低 Agent 重复文件读取开销。

---

## 1. 核心测试集：Memory Challenge Benchmark (55 个案例)

Pico 实现了 Provider-Free 的 **Memory Challenge 测试集**（位于 `pico/evaluation/memory_agent_eval.py`），共包含 **55 个标准化案例**，全面覆盖记忆生命周期：

```text
Memory Challenge (55 Cases)
├── 1. 信息抽取 (Information Extraction) : 9 个案例
├── 2. 知识更新 (Knowledge Update / Supersede) : 9 个案例
├── 3. 多会话推理 (Multi-Session Reasoning) : 9 个案例
├── 4. 时间与冲突推理 (Temporal & Conflict) : 11 个案例
├── 5. 拒答/无答案场景 (Abstention) : 8 个案例
└── 6. Agent 效率 (Agent Efficiency) : 9 个案例
```

---

## 2. 核心实验结果与 4 变体基线对比

实验运行了 4 个变体基线，数据对比展示了完整记忆治理的巨大优势：

| 指标 / 评估维度 | 无记忆 (`memory_off`) | 简单拼接 (`naive_recent`) | 无安全治理 (`unsafe_memory`) | **完整分层记忆 (`memory_on`)** |
| :--- | :---: | :---: | :---: | :---: |
| **Answer Accuracy (回答准确率)** | 21.8% | 54.5% | 81.8% | **94.55%** (52/55 通过) |
| **Evidence Recall@K (证据召回率)** | 0.0% | 48.2% | 100.0% | **100.0%** |
| **Evidence Precision@K (精准率)** | 0.0% | 35.1% | 62.4% | **87.23%** |
| **Poison Quarantine Rate (隔离率)**| N/A | 0.0% | 0.0% | **100.0%** (阻断攻击) |
| **Secret Exposure Rate (泄露率)** | 0.0% | 24.5% | 36.4% | **0.0%** (零泄露) |
| **Stale Use Rate (陈旧事实误用率)**| 0.0% | 42.1% | 28.6% | **0.0%** (零误用) |

## 3. 消融实验：确定性效率收益

在 12 个固定 Coding 任务的消融实验中：
* **重复文件读取**：由 `memory_off` 的 60 次直接降至 **0 次**（降幅 100%）。
* **平均模型尝试次数**：由 2 次降至 **1 次**（尝试减半）。

---

## 4. 失败案例分析 (Lessons Learned)

Memory Challenge 测试集中未通过的 **3 个案例**（52/55 通过）：
* **因果分析**：属于“两条记忆事实存在冲突，但**不存在明确的 `supersede` 覆盖关系**”的边界场景。
* **模型行为**：模型偶尔会盲目选错其中一条，而不是稳妥地做出拒答或要求重新验证。
* **下一步优化**：强化无覆盖链条时的克制答复（Abstention）与重新校验机制。
