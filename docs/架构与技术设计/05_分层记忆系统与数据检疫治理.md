## 5.1 架构总览：3 核心层 + 1 安全隔离层

```
                    ┌───────────────────────────────────┐
                    │ Session History (原始会话交互流)  │
                    └─────────────────┬─────────────────┘
                                      │ 提纯/裁剪
                                      ▼
                    ┌───────────────────────────────────┐
                    │ Working Memory (Session级工作记忆) │
                    └─────────────────┬─────────────────┘
                                      │ 校验/晋升 (Promote)
                                      ▼
┌───────────────────────────┐   ┌───────────────────────────────────┐
│ Memory Quarantine (隔离层) │ ◄─┤ Durable Memory (磁盘持久主题记忆)  │
└───────────────────────────┘   └───────────────────────────────────┘
```

## 5.2 核心治理机制

### 5.1.1 工作记忆容量切片 (Working Memory)
* **`task_summary`**（300字）：维持任务目标。
* **`recent_files`**（8文件）：维护工作现场。
* **`file_summaries`**（6文件）：模块摘要，绑定 `freshness` 时间戳。
* **`episodic_notes`**（12条）：FIFO 短笔记队列。

### 5.1.2 长期记忆主语覆盖 (`supersede`)
当出现新旧矛盾事实时，通过 `_subject_key()` 抽取主语（如 `"database"`）：
* 旧记忆元数据标注 **`status: "superseded"`**（废弃）。
* 新记忆标注 **`supersedes: "old_note_id"`**，建立递进更新链。
* 召回时物理过滤所有 `superseded` 状态的笔记。

### 5.1.3 代码锚点与新鲜度校验 (Evidence Staleness)
绑定源码路径与 `evidence_anchor_hash`（SHA256）。召回时现场重新计算 Hash，若文件被编辑过，打上 `stale_evidence = True` 并拒绝召回，杜绝模型使用过期代码事实。

### 5.1.4 检疫隔离池 (Memory Quarantine)
针对 Prompt 注入攻击或敏感 Key 泄露，打上 `status: "quarantined"` 并存入 `.pico/memory/quarantine/` 隔离池，实现从 Prompt 中的全局物理剔除。

## 5.3 四维确定性召回算分算法

放弃向量 Embedding，采用确定性算分公式：

$$\text{Score} = \text{exact\_tag\_match} \times 1000 + \text{keyword\_overlap} \times 10 + \frac{\text{recency}}{1,000,000} + \frac{\text{note\_index}}{1,000,000,000}$$

排序 Key 为 **`(exact_tag_match, keyword_overlap, recency, note_index)`**，利用 `note_index` 作为平局打破项（Tie-breaker），实现排序 100% 确定不抖动。

## 5.4 实验结果数据 (Memory Challenge)

在 55 个标准 Memory Challenge 案例中：
* **回答准确率 (Accuracy)**：**94.55%** (52/55 通过)。
* **证据召回率 (Recall@K)**：**100.0%**。
* **攻击隔离率 (Poison Quarantine)**：**100.0%**。
* **敏感暴露与过期误用率**：均为 **0.0%**。
* **重复文件读取**：消融实验中由 60 次降至 **0 次**。
